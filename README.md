# RESTAssured_Project

📌 Project Overview

This project automates API testing using Rest Assured with Java, verifying different HTTP methods like GET, POST, PUT, DELETE, and validating responses using TestNG assertions.

🚀 Tech Stack

Java (Programming Language)

Rest Assured (API Testing Framework)

TestNG (Testing Framework)

Maven (Build Tool)

JSON (Data Format for API Requests)

🔧 Project Setup

1️⃣ Prerequisites

Install Java JDK (23)

Install Maven

Install an IDE (Eclipse)
 
📜 Test Scenarios

✅ GET Request: Fetches user details from an API
✅ POST Request: Creates a new user with JSON payload
✅ PUT Request: Updates an existing user
✅ DELETE Request: Deletes a user from the system
